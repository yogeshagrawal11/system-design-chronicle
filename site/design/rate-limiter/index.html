🚦 Distributed Rate Limiter

Decide in under a millisecond whether request #1,000,001 from this API key is allowed, across hundreds of servers and several regions.

A rate limiter caps how many requests a client (API key, user, IP, tenant) may make in a time window, and rejects the rest with 429 Too Many Requests. On a single server it is a hash map of counters. The hard version is distributed: requests for the same key land on hundreds of gateway instances…

🪵 The Log-Structured Merge-Tree (LSM-Tree)

Buffer writes in memory, then merge them to disk in big sorted batches — trading a little read cost for massive write throughput.

The LSM-tree is an index structure for workloads with far more inserts than lookups. Instead of updating a B-tree in place — one random disk read and write per insert — it collects new entries in a small, sorted in-memory component C0, and continuously merges them into a larger on-disk component…

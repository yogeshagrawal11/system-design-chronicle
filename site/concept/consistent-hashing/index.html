💍 Consistent Hashing

Spread keys across servers so adding or removing one moves only a small slice of data.

When data is split across N servers, the naive rule server = hash(key) % N breaks badly when N changes: going from 4 to 5 servers remaps ~80% of keys, which means a cache stampede or a massive data migration. Consistent hashing places both servers and keys on a circular hash space (a *ring*).…

📍 IP Addresses, CIDR & NAT

How every interface gets a routable address, how ranges are carved up, and how private networks reach the internet.

An IP address identifies a network *interface* (not a machine or a user) so routers can deliver packets to it. IPv4 uses 32 bits (203.0.113.42), giving ~4.3 billion addresses, which ran out years ago. IPv6 uses 128 bits (2001:db8::8a2e:370:7334), enough for every grain of sand to have billions.…

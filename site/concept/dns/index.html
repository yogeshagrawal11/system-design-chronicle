📖 DNS (Domain Name System)

The internet's distributed, cached phone book that turns names into addresses, and a powerful traffic-steering tool.

DNS maps human-friendly names (api.example.com) to the data machines need: IP addresses, mail servers, aliases, verification tokens. It is a globally distributed, hierarchical database: root servers know who runs each top-level domain, TLD servers (.com, .io) know who is authoritative for each…

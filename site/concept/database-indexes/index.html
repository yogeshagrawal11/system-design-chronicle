📇 Database Indexes

A sorted side-structure that turns a full table scan into a handful of page reads — paid for on every write.

Without an index, SELECT * FROM users WHERE email = 'ana@x.com' must read every row — on a 100M-row table that is gigabytes of I/O. An index is a separate structure, kept in sync with the table, that maps column values to row locations so the database can jump straight to matches. The workhorse…

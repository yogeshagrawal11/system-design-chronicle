🤖 AI Agents & Tool Use

An LLM in a loop that decides which tools to call next — powerful for open-ended tasks, and a source of new failure modes when used where a fixed workflow would do.

On its own, an LLM can only produce text. Tool use (function calling) lets it *ask* your code to do things: you describe tools as JSON schemas, the model replies with a structured call such as get_invoice(id="INV-881"), your code runs it and feeds the result back. The model never executes…
